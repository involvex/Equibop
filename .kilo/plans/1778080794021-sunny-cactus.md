# Equibop Project Improvement Plan

## Issues Identified

### Issue 1: Electron .exe Not Working When Moved (Missing Main Entry Point)

**Root Cause Analysis:**
When the .exe from the win-unpacked folder is moved/copied to the desktop, Electron cannot find its main entry point. This is caused by:

1. The `electronFuses.onlyLoadAppFromAsar: true` setting in package.json (line 218) - When enabled, the app can ONLY load from an asar archive. If the .exe is moved without the asar file or if the asar path resolution fails, the app won't start.

2. Electron's resource path resolution - When moved outside the packaged directory structure, the relative paths to `resources/app.asar` or `resources/app` may no longer resolve correctly.

3. The `files` glob pattern in electron-builder config uses `"!*"` (exclude all) then includes specific folders. This might not be capturing all necessary files for the unpacked distribution.

**Related Configuration:**
- `package.json:11`: `"main": "dist/js/main.js"`
- `package.json:212-221`: `electronFuses.electronFuses` configuration with `onlyLoadAppFromAsar: true`
- `package.json:80-86`: `build.files` configuration

### Issue 2: General Project Improvements

Areas for improvement based on code review:

1. **Missing electron-builder.yml**: No dedicated electron-builder configuration file for better control
2. **Build artifacts**: The `dist/` folder is in .gitignore but might need better cleanup/build management
3. **CI/CD**: The release workflow doesn't build for macOS (line 42-43 in release.yml skips mac)
4. **Documentation**: Could use improvements for build/deployment instructions
5. **Build script**: The build.mts could benefit from better error handling and logging

**File:** `electron-builder.yml` (new file)

**Content:**
```yaml

productName: Equibop
executableName: equibop

asar: true
directories:
  output: dist
  app: .

  - !*
  - !node_modules
  - dist/js
  - static
  - package.json

  schemes:
    - discord
```
